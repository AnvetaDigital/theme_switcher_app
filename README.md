# Theme Switcher App 🎨

A responsive React + TypeScript application with three unique themes, smooth transitions, and persistent settings.

## Features
- **Three Distinct Themes**
  - **Light Minimalist** (default)
  - **Dark Mode** with sidebar layout
  - **Colorful Card Grid** with playful fonts
- **Theme Persistence** via `localStorage`
- **Multiple Pages** (Home, About, Contact) with React Router
- **Responsive Design** for desktop & mobile
- **API Data** from [("https://dummyjson.com/posts"), ("https://dummyjson.com/products")]
- **Smooth Animations** on theme change

## Tech Stack
React · TypeScript · Context API · Tailwind CSS · React Router ·Framer motion
